03 Architectural Breakdown

Why 64×64 L1-Tiled RGBA + Morton Z Middle-Out Slashes Latency

◆ 64×64 L1-Tiled RGBA Macro-Blocks

Partitioning payloads into 64×64 32-bit RGBA pixel macro-tiles (16 KB each) pins both the active tile pixels and the 4,096-entry Morton Z-order lookup table inside L1 CPU data cache (~1 ns latency), completely eliminating L3/RAM cache-miss cliffs even on 32 MB to 128 MB payloads.

Tile = 64 × 64 px × 4 B = 16,384 B (L1d Cache Pinned)

◆ Morton Z-Order Middle-Out (MZMO)

Interleaving 2D coordinates $(x, y)$ into a 12-bit Morton Z-curve preserves 2D spatial locality while enabling linear traversal. Starting at the tile midpoint ($M = 2048$), Chain α marches backward ($2047 o 0$) while Chain β marches forward ($2048 o 4095$) simultaneously with domain-separated per-tile seeds.

Z = interleave(x, y)  |  α: [2047..0] ∥ β: [2048..4095]

◆ Zero-ARX Critical-Path Latency

Traditional 20-round ARX ciphers suffer from long serial carry-dependency chains across 80+ sequential additions and rotations per block. By replacing multi-round ARX loops with single-pass 32-bit integer finalizers and L1-local Morton Z-matrix scattering, 2tangno4 achieves massive throughput across all buffer sizes.

Latency: 2,048 Dual-Chain Word Steps / 16 KB Tile (0 ARX Rounds)
