03 Architectural Breakdown

Dual-Chain Parallelism & Cryptographic Margin

◆ Dual-Axis Parallel Execution

2tango4x2 parallelizes across two levels simultaneously: intra-block dual chains (Lane Alpha and Lane Beta running independent 32-bit ARX quarter-steps before converging at a synchronized cross-lane bridge) and inter-block counter pipelines (ctr and ctr+1 advancing together to emit 64 keystream bytes per step, halving loop overhead and keeping CPU execution ports saturated).

Step(K, N, ctr) → Block(ctr) ∥ Block(ctr + 1) = 64 Bytes

◆ 1:1 Encryption / Decryption Parity

Because 2tango4x2 operates as a counter-mode ARX keystream generator, decryption never needs to invert modular additions or cross-lane rotations. Both directions evaluate the exact same forward keystream function and XOR it against the payload—giving identical throughput and parallel block scaling for encryption and decryption.

C = P ⊕ KS(K, N, ctr)  ⇔  P = C ⊕ KS(K, N, ctr)

◆ 20 Rounds + Feed-Forward Lock

Running 20 rounds yields 10 complete cross-lane mixing cycles—matching ChaCha20's diffusion depth so carry bits propagate across all 8 state words ten times over. Adding the initial state back at the end (Z = S₀ + S₂₀ mod 2³²) makes the block transform non-invertible, preventing backward state recovery while preserving 256-bit post-quantum strength against Grover's search.

Z[i] = (S₀[i] + S₂₀[i]) >>> 0  (i ∈ 0..7)
